## 執行時的偏離與補充（請確認）

1. **字型**：企畫書 7.5 要求 `next/font/google`。為了讓 build 不依賴外網，改用系統 CJK 字型堆疊（Noto Sans/Serif TC → PingFang → 微軟正黑體）。要嚴格照企畫書，之後可改回。
2. **D-05「只存該 task 的 key」**：新 key 已依 task 分開存；但存檔時是「既有 row 內容 ＋ 新內容」合併寫回，**不會刪掉舊 row 裡任何舊答案**（R-7 優先）。因此舊 TaskFlow 留下的「每個 row 都有整階段答案」不會被清掉。待 Phase 8 驗收後再決定是否清理。
3. **字數計法**：附錄 C 手算 30 字。程式重算：不計【】為 26 字（計【】為 30，Artifact 計法為 27）。三種算法對範例句都 >25，結論相同。
4. **`consult_session` 沒有做「4-A＋4-D 併頁」**（8.9 的 `p.t4.merge`），改保留 4-A、4-D 各一頁，避免重複 block 定義。
5. **checklist 的「自動判定」**只顯示「依你的答案已達成」提示，不代替學員勾選；因此 `*.done.checks` 只存學員手動勾的。
6. **`dropped` 為空**：舊解析器產生的 137 個欄位全部有對應。
