# 創客學院｜Codex Starter Pack

本資料夾是給 Codex 專案使用的第一版規格與內容結構。

## 包含

- `AGENTS.md`：Codex 長期專案規則
- `docs/GITHUB_ISSUE_001.md`：第一個 GitHub Issue，可直接貼到 repository
- `docs/TASKS.md`：分 Epic / Task 的開發清單
- `docs/COURSE_CONTENT_IMPORT_GUIDE.md`：未來新增課程 Markdown 的標準流程
- `content/source/stage-02/`：目前已提供的階段二講義與作業原始檔
- `content/source/stage-01/`：階段一的預留目錄，待實際原始檔加入

## 使用方式

先將整個資料夾內容放入 Codex 專案根目錄，再讓 Codex 先讀 `AGENTS.md`，之後使用 `docs/GITHUB_ISSUE_001.md` 作為第一個實作 Issue。
