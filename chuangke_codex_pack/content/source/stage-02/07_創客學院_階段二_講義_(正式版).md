# 階段二：賣爆賺錢的商業定位

**創客學院｜六階段課程　模組二**

# 2.0 階段二導讀

## 一、你現在在系統的哪個位置

階段一你確認了「**這件事值不值得做**」。

階段二要確認的是：**做出來，賣不賣得掉。**

這是整套系統的分水嶺。

因為後面四個階段——廣告、銷售頁、官方 LINE、對談——**全部都是在放大階段二的答案。**

定位對了，廣告投得越準，賺得越快。
定位錯了，廣告投得越準，錯得越快。

這就是為什麼不能跳過這一階段直接去學投廣告。

**廣告不會幫你想清楚，只會幫你放大。**

## 二、這個階段的五節在做什麼

跟階段一一樣，五節是一條線：

| 節 | 在回答的問題 |
|---|---|
| **2.1 市場調查與市場分析** | 大家都在講什麼？那還有什麼沒人講？ |
| **2.2 受眾與用戶畫像** | 我要對誰說話？他長什麼樣子？ |
| **2.3 獨特的精準定位** | 我站哪個位置？一句話怎麼講？ |
| **2.4 好產品與高價格** | 我賣什麼？憑什麼賣這個價？ |
| **2.5 賣爆的成交環節** | 他說「我再想想」的時候，我少給了什麼？ |

前三節決定**你是誰**，後兩節決定**你賣什麼、賣多少**。

## 三、階段一的東西，這裡全部會用到

**先把階段一的手冊拿出來放旁邊。** 這一階段有一半的題目，是從階段一的答案長出來的。

| 你手上的 | 這一階段拿它做什麼 | 在哪一節 |
|---|---|---|
| **10 句原話** | 分成三層，挖出最底層那句恐懼 | 2.1 |
| **3 個競爭者** | 拆成五欄，找出沒人站的位置 | 2.1 |
| **你服務誰**（1.1-A） | 縮成一個有名字的人 | 2.2 |
| **為什麼是你**（1.1-C） | 變成定位句的最後一格 | 2.3 |
| **我不收誰**（1.4-B） | 變成高價的第三根支柱 | 2.4 |

**沒填階段一就跳過來的話，2.1 第一題就會卡住。**

### ※ 還有一件事，等一下作業會叫你做 ※

階段一 1.1-B，你寫過一句「他會親口說的話」。

**那一句是你猜的。**

當時你還沒去撿原話，所以只能憑印象寫——講義也明說了，先寫一句，查完再改。

現在你手上有十句真的。**作業 2.1-A 會請你把兩句並排放一次，比對一下。**

為什麼要花時間做這個比較？

因為「**我以為**」和「**他實際說**」之間的那段距離，就是專業者最容易掉進去的坑。

你太熟這個領域了，熟到你會用自己的角度去想客人。這不是能力問題，是位置問題——**你站在會的那一邊，他站在不會的那一邊。**

這個坑你這一輩子都會一直掉。差別只在於：你有沒有一個習慣，每隔一陣子就把兩邊並排看一次。

## 四、學完這個階段，你手上會有

1. **一句「沒有人在講的是＿＿」**
   你的空白地帶

2. **一份用戶畫像**
   一個有名字的人，不是一段年齡範圍

3. **一句定位句**
   問「你跟別人有什麼不一樣」，你有答案

4. **一個產品和一個價格**
   而且知道為什麼賣這個價

5. **一套成交方案**
   能處理「我再想想」的那一套

## 五、這一階段的標準，跟階段一不一樣

階段一我一直跟你說：**不確定就寫「暫定」，不要停下來想。**

**這一階段不一樣。**

開頭講過了，後面四個階段都在放大這一頁。所以標準要提高一階：

> 階段一的標準是「**有第一版**」。
> 階段二的標準是「**你自己唸出來會相信**」。

不是要你寫到完美——**是要你寫到自己看了不心虛。**

如果寫完某一格，你心裡有個聲音在說「這好像有點唬爛」，那就是還沒好。回去改那一格。

## 六、這個階段的定調句

> 定位不是把你變得更好，是讓你在客戶心裡變得不一樣。

# 2.1 市場調查與市場分析

## 一、這堂課要解決的問題

階段一你蒐集了 10 句原話、3 個競爭者、3 個破口。

**那些是食材。這堂課要把食材做成菜餚。**

## 二、核心觀念

大部分人做市調，是為了回答「這個市場有多大」。

**那個問題其實不重要。** 市場再大，跟你能不能賺到錢是兩件事。

真正要回答的問題只有一個：

> **大家都在講什麼？那還有什麼沒人講？**

因為客人的腦袋裡已經被競爭者塞滿了。

你講一樣的話，他分不出你；
你講沒人講過的話，他才會停下來。

**市調不是為了了解市場，是為了找出那個沒被佔走的位置。**

## 三、方法：需求三層地圖

把階段一蒐集到的原話，分成三類：

| 層次 | 是什麼 | 判斷方式 |
|---|---|---|
| **A. 表面痛** | 他嘴巴上說的問題 | 「我不會 OO」 |
| **B. 真正要的結果** | 他其實想拿到的東西 | 「我想要 OO」 |
| **C. 說不出口的恐懼** | 他不會公開講的 | 「我怕我根本 OO」 |

**例：**

- 表面痛：「我不會行銷。」
- 真正要的：「我想要每個月都有穩定的客人。」
- 恐懼：「我怕我根本不是做生意的料。」

**前兩層每個同行都在講，第三層講的人講到心裡去。**

### 為什麼第三層最值錢

因為**幾乎沒有競爭者在那裡**。

原因很簡單：**恐懼講出來會不舒服。** 你的同行都很客氣，所以他們的文案停在前兩層——講痛點、講願景，很安全，也很沒記憶點。

但客人自己心裡知道那第三層在。**當有人講出來的時候，他的反應不是「這家不錯」，是「他怎麼知道」。**

### 你會發現第三層是空的

**這很正常，而且幾乎每個人第一次做都是空的。**

因為沒有人會公開講自己的恐懼。你去社團、去留言區撿回來的十句，撿到的幾乎全是前兩層。

那怎麼辦？**從表面痛往下追問三次「所以呢」。**

> 我不會行銷 → **所以呢？**
> → 我招不到人 → **所以呢？**
> → 我做不下去 → **所以呢？**
> → **我怕我根本不是做生意的料**

**追到你自己讀了會有一點不舒服，那一層就到了。**

追問的具體做法，作業 2.1-A 會帶你走一次。

## 四、方法：競品拆解五欄

把階段一找到的 3 個競爭者，拆成這五欄：

| 競品 | 賣給誰 | 主打什麼 | 價格帶 | 承諾什麼 | 最大弱點 |
|---|---|---|---|---|---|

**看的重點不是誰最強，是他們有沒有共同點。**

### 這張表的結論：空白地帶

拆完之後，只看一欄——**「主打什麼」。**

把三家的並排放：

> 如果三家講的是 A、B、C，那**沒有人在講的 D，就是你的位置。**

**例（補習市場）：**

- 競品 1 主打：師資強
- 競品 2 主打：老師多可以挑
- 競品 3 主打：價格彈性

三家講的是師資、選擇、價格。

**沒有一家在講「怎麼教」。**

那「教法」就是空白地帶。

## 五、案例｜我查易學院的競品，查到什麼

### 第一張表：三層需求

我從家長諮詢裡撿回來的原話，最常聽到的是這幾句：

- 「補習費花了快十萬，段考數學還是 42 分。」
- 「他不是不認真，評量都有寫，就是考不好。」
- **「他就是沒有數學細胞。」**

前兩句很好分——**表面痛**。

第三句不一樣。它聽起來也像抱怨，但它其實已經在下結論了：不是「他還不會」，是「**他天生就不行**」。

有些家長還會講得更直接：「他是文組的」「他沒有理科腦」。

**這句往下追三次：**

> 他就是沒有數學細胞 → **所以呢？**
> → 所以再怎麼補也就是這樣了 → **所以呢？**
> → 所以我其實已經不太期待他會變好 → **所以呢？**
> → **我怕我已經先放棄我自己的孩子了**

追到這裡就停了，因為我自己讀了會不舒服。

**沒有一個家長講得出這句話，因為講出來等於承認自己是什麼樣的媽媽。**

但這句話解釋了很多事——解釋她為什麼一直換補習班（還沒真的放棄），也解釋她為什麼問「現在換來得及嗎」（她在找一個可以繼續相信的理由）。

### 第二張表：競品在講什麼

我真的去 Meta 廣告檔案庫查了，台灣、所有廣告、關鍵字「國中數學」。

三家投超過一個月的，主打分別是：

| 競品 | 主打什麼 |
|---|---|
| 大型連鎖補習班 | 師資強、升學榜單 |
| 線上家教媒合平台 | 老師數量多、可以挑 |
| 個人接案家教 | 價格彈性、時間配合 |

**師資、選擇、價格。**

但查的過程中我發現一件更有用的事：**他們的廣告寫得很淺。**

大多是師資介紹、榜單、優惠、開課資訊。少數幾家有講到教學，講的是「**因材施教**」「**化繁為簡**」「**啟發式教學**」——

**這些話聽起來很對，但你能照著做嗎？**

家長也不能。她看完只知道「這家好像不錯」，但她沒辦法判斷這跟上一家有什麼不同。

### 所以我的空白地帶是

> **沒有人在講「怎麼教」。**

不是沒人提到教學，是**沒有人講得出一個具體的步驟和流程**。整個市場的溝通都停在「我是誰」和「我的理念是什麼」。

而我可以講得出來——我把解題流程總結成三個明確的步驟，**那就變成我的賣點。**

### 兩張表放在一起看

| | |
|---|---|
| **她心裡最深的那句** | 我怕我已經先放棄我自己的孩子了 |
| **市場給她的回應** | 師資很強、老師很多、價格優惠、我們因材施教 |

**沒有一個回應到那句話。**

因為要回應「他是不是天生就不行」，你必須講得出**他到底卡在哪一步**——而那需要一個具體的流程，不是一句理念。

**這就是空白。**

## 六、空白地帶的用途：它是你的新品類

找出空白，不是為了證明你比較特別。**是為了讓你有一個小池塘。**

你現在待的是一個大賽道——教數學、教霧眉、教投資。那個賽道裡已經有前三名了，而且他們資源比你多十倍，你擠不進去。

但如果你把賽道切小：

> 不是「補習班」，是「**解題方法教學**」
> 不是「霧眉技術班」，是「**手感養成教學**」
> 不預測股市方向，**只做風險控制**

**在切小的那個池塘裡，你是第一名，因為只有你一個。**

而且切小之後，你的宣傳方式也跟著變——你不用再跟人比師資、比價格，**你比的是那個只有你在講的東西。**

### 順便講一件事：你可能已經有位置了，只是講不出來

有些人做這一題會卡住，不是因為找不到空白，是因為**他的空白還在自己身上。**

「我就是比較會抓學生卡在哪」「我看一眼就知道他問題在哪」——

**這種話是真的，但它對客人沒有任何意義**，因為每一個老師都可以這樣講。

我自己的三步驟解題法就是這樣長出來的。

一開始我也只會說「我能看出他卡在哪」。後來我是**從大量的教學實戰經驗裡，去總結那些可以被具體化、可以被分享出去的部分**——我每次判斷的時候，到底在看什麼？順序是什麼？

拆完之後才變成三個明確的步驟。**而拆出來的那一刻，它才從「我的直覺」變成「可以賣的東西」。**

**如果你現在講不出步驟，那不是壞消息。** 你不是沒有東西，你是有東西但還沒變成別人拿得到的形式。

**不用換位置，只要多花時間拆。**

## 七、常見錯誤

**錯誤一：把市調做成問卷**

你問「你需要什麼」，得到的都是禮貌話。
人不知道自己要什麼，但他知道自己討厭什麼。

*重點：看抱怨，不要問需求。*

**錯誤二：只研究做得最好的那一家**

最強的那家通常已經佔住最大的位置，你打不動。

*重點：研究第二、第三名的弱點，那裡才有縫。*

**錯誤三：做完市調，沒有結論**

蒐集了一堆資料，最後還是憑感覺做決定。
市調的產出只有一個：**一句「沒有人在講的話」。**

*重點：找不到那句話，等於沒做。*

**錯誤四：恐懼那一層用猜的**

「我猜他應該是怕沒面子吧」——這是你的投射，不是他的恐懼。

*重點：一定要從他真的講過的表面痛往下追。追問的起點必須是原話。*

## 八、這一節你要產出什麼

到作業本**任務 2.1**，你會產出三樣東西：

1. **分好三層的原話**，特別是恐懼那一層
2. **競品拆解五欄表**（3 家）
3. **一句「沒有人在講的是＿＿」**

**第三樣是這一節唯一的產出。** 前面兩張表都是為了它。

而那一句話，會變成你接下來整個定位的起點——2.3 寫定位句的時候，第一個要看的就是它。

> 你要找的不是最大的市場，是最空的那個位置。

# 2.2 受眾與用戶畫像的選擇

## 一、這堂課要解決的問題

問你的客人是誰，你說「25 到 45 歲、女性、對自我成長有興趣」。

**那不是用戶畫像，那是廣告後台的欄位。**

照那個描述，你想不出任何一句他會有感覺的話。

## 二、核心觀念

用戶畫像的目的不是描述一群人，是「**讓你能對一個人說話**」。

> 你講給一個人聽，一群人才會覺得你在講他。
> 你講給一群人聽，沒有人覺得你在講他。

所以畫像要一路縮：

```
一群人  →  一個人  →  一個人的某一個時刻
```

### 為什麼一定要縮小範圍

因為**你怕的事情不會發生。**

大部分人不敢縮，是怕「講得太窄，客人變少」。

**實際上相反：講得夠窄，被講到的那個人才會停下來。**

而沒被講到的人，本來也不會買。

**你損失的是本來就不會成交的人，換到的是真的會停下來的那個人。**

### 這一節跟階段一是什麼關係

階段一 1.1-A，你已經選過「你服務誰」了——用的是四格軸（還沒動作／自己想辦法／花過錢沒解決／有結果想更好）。

**那一格選的是「哪一種人」，這一節要做的是「把那種人縮成一個人」。**

| | 階段一 1.1-A | 這一節 2.2 |
|---|---|---|
| 產出 | 補過也請過家教、但成績沒起色的國中生家長 | 一個叫做 OO、45 歲、在竹科做行政的媽媽 |
| 用途 | 決定廣告投給哪一群 | 決定文案怎麼寫 |

**兩個都要。** 前者決定廣告後台的設定，後者決定你打得出那句話。

## 三、方法：畫像六格

不要寫小論文，就填這六格：

| 格 | 問題 | 為什麼要問 |
|---|---|---|
| 1 | 他叫什麼名字、幾歲、做什麼 | 逼你具體化 |
| 2 | 他的一天長什麼樣子 | 找出你的內容會在什麼時候被看到 |
| 3 | 他現在卡在哪一件事 | 你的鉤子從這裡來 |
| 4 | 他已經試過什麼？結果怎樣 | 決定你**不能說什麼**（他試過了，別再推薦一次） |
| 5 | 他半夜滑手機在看什麼 | 決定你的廣告要長什麼樣 |
| 6 | 這件事他會跟誰討論 | 找出真正的決策者 |

### 第 1 格：一定要有名字

有名字之後，你寫文案時腦袋裡才會有人。

**這不是形式，是有實際作用的。**

你對著「25 到 45 歲女性」這幾個字，寫不出任何一句她會有感覺的話——因為那不是一個人，那是一個範圍。

但你對著「淑芬，42 歲，孩子剛升國一」，就可以開始想她昨天晚上在做什麼。

**差別不在資料多寡，在於你腦袋裡有沒有一個人。**

### 第 4 格：這一格決定你不能說什麼

階段一你已經知道他「花過錢找別人解決但沒解決」。**這裡要問得更細：他花在哪一家？那家承諾了什麼？為什麼沒兌現？**

因為**他試過而且失敗的方法，你再推薦一次，他會直接關掉。**

而且這一格有一個額外的好處：**他失敗的地方，通常就是你的切入點。**

他上過的那堂課教了什麼、漏了什麼——那個漏掉的，可能正好是你 2.1 找出來的空白。

### 第 6 格：很多人漏掉這一格

有些生意的**付錢的人和使用的人不是同一個**。

例：家長和孩子、老闆和員工、飼主和寵物、子女和長輩。

**搞錯對象，整套訊息都會歪。**

而且就算付錢和使用是同一個人，也常常有第二個人要被說服——配偶、合夥人、家裡管錢的那個。

**如果第 6 格不是「自己決定」，你的頁面要有一段是寫給那個人看的。**

## 四、方法：鎖定一個時刻

畫像的最後一步，是把它縮到**一個具體場景**。

不是「他很焦慮」，而是：

> **週日晚上十點，他滑到同行貼出「這個月招滿了」的限時動態。**
> **關掉手機，發現明天早上還是一堂課都沒有。**

### 為什麼要具體到這種程度

因為**焦慮沒有畫面，畫面才有人。**

「他很焦慮」這四個字，你沒辦法從裡面長出任何一句文案。

但上面那個場景裡，你可以長出至少三種開頭——從限時動態切入、從關掉手機那個動作切入、從明天早上切入。

**這一段之後會直接變成你的廣告開場。**

### 一個時刻要有什麼

三樣東西，缺一個就不夠具體：

| | 例子 |
|---|---|
| **時間** | 週日晚上十點 |
| **他正在做什麼／看到什麼** | 滑到同行貼出「這個月招滿了」 |
| **心裡閃過什麼** | 明天早上還是一堂課都沒有 |

**注意最後一項不是「他覺得很焦慮」，是他腦袋裡真的閃過的那個念頭。**

## 五、案例｜同一句原話，兩種畫像

我在易學院一開始寫的受眾是「**中弱程度的學生**」。

那是我的分類方式——我在教學現場就是這樣看學生的。**但家長不是用程度在看自己的孩子。**

所以我改了。而改完之後我才發現一件事：**同一句原話，可以長出兩個完全不同的人。**

那句原話是：「**上課都聽得懂，回家自己寫就不會。**」

### 畫像 A：國一的媽媽

| 格 | 內容 |
|---|---|
| 他是誰 | 淑芬，42 歲，孩子剛升國一 |
| 卡在哪 | 小學數學都九十幾分，上國中第一次段考掉到六十幾 |
| 試過什麼 | 還沒補，先買了評量自己盯，盯了兩個月沒用 |
| 半夜在看什麼 | 媽媽社團裡討論「國一要不要補」的貼文 |
| 跟誰討論 | 老公，但老公覺得再看看 |

**她的那個時刻：**

> 星期三晚上十一點，她收走孩子桌上的評量，看到整頁只寫了三題。
> 想到上禮拜才跟老公說「應該還好吧」。

### 畫像 B：國三的媽媽

| 格 | 內容 |
|---|---|
| 他是誰 | 麗華，47 歲，孩子國三下 |
| 卡在哪 | 補了兩年，模擬考數學還是 B |
| 試過什麼 | 大型補習班一年、家教半年，都說孩子沒問題 |
| 半夜在看什麼 | 搜尋「會考數學 剩三個月 來得及嗎」 |
| 跟誰討論 | 沒有人，自己決定 |

**她的那個時刻：**

> 模擬考成績單發下來那天晚上，她拿出去年的成績單比對，發現數學一模一樣。
> 想到會考剩不到一百天。

### 這兩個人要用完全不同的話

**淑芬要的是「還來得及，而且現在處理最省力」。**

**麗華要的是「剩下的時間，最有效的做法是什麼」。**

同一句「你不用自己想清楚全部，我陪你做出第一版」——
對淑芬有效（她還在觀望），對麗華沒用（她要的是速度）。

**所以我的廣告文案是分年級寫的，不是一篇打三個年級。**

> **這就是這一節的價值。**
> 階段一 1.1-A 告訴你「要打國中生家長」。
> 但到了要寫字的時候，「國中生家長」還是寫不出東西——**你要先知道是淑芬還是麗華。**

## 六、常見錯誤

**錯誤一：用人口統計代替畫像**

年齡性別地區是廣告後台的設定，不是畫像。

*結論：畫像要能讓你寫出他會說的話。*

**錯誤二：用自己投射**

「我當初就是這樣，所以他們也是。」

你已經走過來了，**你的記憶會美化。**

*結論：回去看原話，不要靠回憶。*

**錯誤三：同時服務多種人**

「我的課適合初學者、也適合進階、也適合想轉職的」——
這句話一出來，三種人都不覺得是在講自己。

*結論：專注一種，不要貪心。*

**錯誤四：畫了一個你希望的人，不是真的存在的人**

「他很有行動力、願意投入、預算充足」——這是你的理想客戶，不是你的畫像。

**畫像要照著原話畫，不是照著願望畫。**

*結論：六格裡每一格，你都要答得出「這是從哪句原話來的」。*

## 七、這一節你要產出什麼

到作業本**任務 2.2**，你會產出三樣東西：

1. **畫像六格**，而且他有名字
2. **一個具體的時刻**（有時間、有畫面、有那個念頭）
3. **三句他的口吻的話**

**第二樣最重要。** 它會直接變成你階段三的廣告第一句。

> 你損失的是本來就不會買的人，換到的是真的會停下來的那個人。

# 2.3 獨特的精準定位

## 一、這堂課要解決的問題

客人問你：「**你跟別人有什麼不一樣？**」

你如果答不出來，或是講了一大串，成交就在那一刻結束了。

## 二、核心觀念：定位是佔位，不是變好

人的腦袋容量有限。

每一個類別，他只記得住兩到三個品牌名字。

想到手搖飲，你想得出兩三個牌子。想第四個，就要想很久。

**所以定位不是「我比較好」，是「我在他心裡佔哪一格」。**

如果那一格已經被別人佔滿了，你再好也擠不進去——因為他根本沒有空位放你。

那怎麼辦？

> **進不了前三名，就自己開一個新的類別，然後當那個類別的第一名。**

### 三條路，你只有一條能走

| | 這條路是什麼 | 能不能走 |
|---|---|---|
| **第一條** | 在既有類別裡當第一 | **不能。** 需要比對手多十倍的資源 |
| **第二條** | 開一個新類別 | 可以，但你要有一個沒人站的位置 |
| **第三條** | 對抗定位——他們往東，你往西 | **最快的一條，因為你可以借他們的力** |

第二條和第三條其實是同一件事的兩個說法。

**你 2.1 找出來的空白地帶，就是那個新類別。** 而站進去的方法，就是第三條——**把大家都在講的話反過來講。**

## 三、方法：對抗定位三步驟

### 步驟 1：找出他們的共同前提

**這是整個階段二最難的一題，所以我把它拆開來教。**

先講清楚要找的是什麼。

**不是**他們的賣點——賣點是他們說出來的話。
**是**他們都沒有質疑過的那個假設——那句話他們沒說，但他們整套作法都建立在上面。

例：

> 三家補習班，一家講師資、一家講老師多、一家講價格。
> **賣點三個都不一樣，但他們共同預設了一件事：數學要好，就是要多寫題目。**
>
> 沒有一家說過這句話。但你看他們的作法——大量講義、題庫、加強班——**全部都建立在這個假設上。**

#### 怎麼把假設挖出來

不要用想的。**用填句子的。**

回去看 2.1-B 的五欄表，把三家的作法攤開來，問這三個問題：

| # | 問題 | 你在找什麼 |
|---|---|---|
| **①** | **他們都要客人做到什麼？** | 每一家都預設客人要出的那份力 |
| **②** | **他們都預設要花多久？** | 時間、次數、堂數、頻率 |
| **③** | **他們都照什麼順序做？** | 先做什麼、再做什麼 |

**三題各答一句，然後挑一句你最有把握的，那就是你要反過來的那一句。**

三題的選項和填法，**作業 2.3-A 步驟 1 會帶你走一次。**

#### 如果你是做服務的，第①題換個問法

第①題問的是「客人要出的力」。但**服務類的客人主要是付錢，不太需要自己動**——所以這題常常填不出東西。

換成問：

> **這一行有什麼事情，大家都當成正常的？**

就是那種你跟客人解釋過很多次的事——「這個本來就會這樣」「每個人都是這樣」。

看幾個例子就懂了：

| 行業 | 大家都當成正常的 |
|---|---|
| 居家清潔 | 清完兩三週又亂回去 |
| 寵物美容 | 狗會怕、會抖、會抗拒 |
| 健身 | 會痠痛好幾天 |
| 補教 | 前期看不到成績 |
| 霧眉教學 | 學完還是不敢接客 |

**一個產業默認的事，通常就是沒人想解決的事。那裡常常有位置。**

#### 三句都填不出來？換這個問法

> **他們的客人裡面，一定會有一種人是失敗的。那種人為什麼失敗？**

- 補教：**認真寫了很多題目，但還是考不好的孩子**
- 健身：**很認真去，但身材沒變的人**
- 霧眉：**證照拿到了，但接不到客人的人**

**每一個失敗案例，都在指向一個沒被質疑的假設。**

寫了很多題目還是考不好 → 代表「多寫題目就會好」這個假設有洞。

**那個洞，就是你的位置。**

### 步驟 2：把它反過來

把找到的那句話，寫成相反的主張。

| 大家都覺得 | 我主張 |
|---|---|
| 先做課再賣 | **先招生，再造課** |
| 多寫題目 | **不用等他看懂，先給步驟讓他敢動筆** |
| 天天練、練到力竭 | **不練到力竭，每一組留兩下** |
| 先學完技術，再開始接客 | **先敢動手，技術在接客的過程中長** |
| 狗會怕是正常的 | **第一次不剪，先讓牠不怕** |

**反過來的時候要注意一件事：不要反成「我比較好」。**

- ✗ 「別人教得不夠細，我教得比較細」——這不是反過來，這是同一條路上比高低
- ✓ 「別人教技術，我教怎麼敢」——**這是換一條路**

**判斷標準：反過來之後，你們兩個還在比同一件事嗎？**

還在比，就沒反成功。

### 步驟 3：檢查你敢不敢說

反過來的那句話，會讓一部分人不同意，甚至覺得你在講幹話。

**那就對了。**

> **沒有人反對的定位，就不是定位。**

一句話如果所有人都點頭，代表它是常識。**常識不會讓人記住你。**

## 四、方法：定位句公式

把上面的結論，填進這個句子：

```
對【誰】而言，
我是唯一【做什麼】的【類別】，
因為【憑什麼】。
```

**例：**

> 對【已經在教、但收入卡在鐘點費的技術型講師】而言，
> 我是唯一【主張先招生、再造課】的【招生系統教學】，
> 因為【我把找客人的流程拆成可以照著做的三步驟，不需要露臉經營自媒體】。

### 四格各自從哪裡來

| 格 | 從哪裡來 | 注意 |
|---|---|---|
| **誰** | 階段一 1.1-A | 直接抄 |
| **做什麼** | 步驟 2 的主張 | 就是你反過來的那一句 |
| **類別** | 2.1 找出的空白地帶 | **不要寫「課程」**，寫得具體一點 |
| **憑什麼** | 階段一 1.1-C 選的切角 | 方法名稱／經歷／成果，三選一 |

**第三格是最多人填錯的。**

「線上課程」「一對一教學」——**這些是交付形式，不是類別。**

類別要能讓人一聽就知道**你跟誰不一樣**：

| ✗ 交付形式 | ✓ 類別 |
|---|---|
| 數學家教 | 解題方法教學 |
| 霧眉課程 | 手感養成教學 |
| 投資課 | 風險控制教學 |

**你 2.1 寫的那句「沒有人在講的是＿＿」，把它變成一個名詞，就是這一格。**

### 定位句 ≠ 你的完整論證

你反過來的那句主張，可能需要鋪陳才講得清楚。**那很正常。**

但**定位句必須能單獨站住**——因為它會出現在廣告第一行、銷售頁標題、你的自我介紹。那些場合沒有時間鋪陳。

所以要分開兩個東西：

| | 這是什麼 | 用在哪 |
|---|---|---|
| **你的論證** | 完整的推理，可能要講三分鐘 | 諮詢、對談、銷售頁內文 |
| **你的定位句** | 論證的結論，一句話 | 廣告第一行、自我介紹 |

**易學院的例子：**

> **論證**：閱讀理解力跟能不能寫出來是兩件事。孩子卡住不是因為讀不懂，是因為拿到題目不知道先做什麼。所以要給他一套 SOP，讓他只專注在問題和他學過的工具上。
>
> **定位句**：**先有步驟，才敢動筆。**

**論證是給已經願意聽你講三分鐘的人；定位句是給只願意看你三秒的人。**

兩個都要有，但**先寫論證，再從裡面挑出那一句**。倒過來寫會寫出一句好聽但空的話。

## 五、案例｜易學院的定位句是怎麼長出來的

### 步驟 1：三家的共同前提

2.1 查出來的三家，賣點是師資、選擇、價格。

用三個問題填：

- ① 他們都要孩子**多寫題目、多練習**
- ② 他們都預設這件事要**一整個學期以上才看得到**
- ③ 他們都是先**看懂題目**，再**動筆算**

**我挑第三句。**

因為那正好對上家長最常講的那句「上課都聽得懂，回家自己寫就不會」——**聽得懂，代表他讀得懂。但他還是不會寫。**

所以「先看懂再動筆」這個順序，根本沒有解釋他為什麼卡住。

### 步驟 2：反過來

我主張：

> **不用等他「看懂」才動筆。給他一套拿到題目之後的固定步驟，他就敢寫。**
> **寫下去之後，他學過的工具自己會用上。**

### 步驟 3：敢不敢說

會不會有人反對？**會。**

現在滿街都在講「素養題考的是閱讀理解」「孩子是讀不懂題目」。我等於在說：**閱讀理解和能不能寫出來，是兩件事。**

**那就對了。**

### 套進公式

> 對【補過也請過家教、但孩子成績就是沒起色的國中生家長】而言，
> 我是唯一【教一套解題 SOP、讓孩子敢動筆】的【解題方法教學】，
> 因為【我有一套三步驟解題法，能當場指出孩子卡在哪一步】。

**濃縮版：先有步驟，才敢動筆。**

**注意第三格：我寫的不是「線上數學家教」，是「解題方法教學」。**

因為「數學家教」這個類別已經滿了——裡面有補習班、有平台、有無數個接案老師，我擠不進去。

**「解題方法教學」是空的，而且是我 2.1 查出來的那個空白。**

## 六、常見錯誤

**錯誤一：把定位寫成優點清單**

「專業、用心、量身訂做、經驗豐富」——每一個同行都可以照抄，等於沒寫。

**錯誤二：怕得罪人，所以講得很安全**

安全的話沒有記憶點。**你要的不是所有人喜歡你，是一小群人非你不可。**

**錯誤三：定位跟著客人改**

這個客人說要 A 你就講 A，下個客人說要 B 你就講 B。

**定位是你選一群人，不是讓每群人都選你。**

**錯誤四：反過來之後，還在比同一件事**

「別人教得不夠細，我教得比較細」——這是在同一條路上比高低，不是換一條路。

**如果客人還是會拿你跟他們比較，那你就沒有站到新的位置。**

## 七、這一節你要產出什麼

到作業本**任務 2.3**，你會產出兩樣東西：

1. **一句完整的定位句**（四格都填完）
2. **一句 15 字以內的濃縮版**，可以直接當廣告標題

寫完之後要過**三個測試**——複述、反對、排除。

作業會帶你走一次。**每一個測試都有「過的標準」和「沒過怎麼辦」**，沒過的會直接告訴你回去改哪一格。

其中複述測試要找一個外行朋友聽；**身邊沒有人的話，作業裡有一條自己做的走法。**

> 沒有人反對的定位，就不是定位。

# 2.4 好產品與高價格

## 一、這堂課要解決的問題

你知道自己該漲價，但每次要報價，**話到嘴邊就軟掉**。

或者你已經開了低價，結果忙到不行、賺得也不多，而且客人還很難搞。

## 二、核心觀念：低價才是那條難走的路

多數人以為低價比較好賣。**實際上低價有三個致命傷：**

### 第一，低價會暗示低價值

同一堂課賣 3,000 和賣 30,000，客人對「這東西有沒有用」的判斷完全不同。

**價格本身就是訊息。**

### 第二，低價吸引比價的人

用價格吸引來的客人，會被更低的價格帶走。

因為他買的是價格，不是價值。

### 第三，也是最致命的：長期低利潤，廣告無法放量

這一點很少人講，但它決定你能做多大。

**廣告的邏輯很簡單：有效之後，加預算，多帶一些人進來。**

但要加得下去，有一個前提——**你多帶進來的那些人，要賺得回你多花的那筆錢。**

> 你賣 3,000，扣掉成本剩不到一半。
> 那你每帶進一個客人能花的錢，大概就一千出頭。
>
> **超過這個數字，你就是做一單賠一單。**

所以低價的人會卡在一個很尷尬的地方：**廣告有效，但你不敢加。**

加了就虧，不加就一直只有這麼多人。

**他不是做不起來，是做不大。**

賣 3 萬的人不一樣。他每帶進一個客人可以花的錢多好幾倍，所以他可以往上加——**加到市場給得出的量為止。**

#### 這不是在說「廣告很貴」

廣告的成本是可以壓的，那是階段四要教的事。

**這裡講的是另一件事：你的利潤，決定了你的廣告能開到多大。**

而且這件事會越來越明顯——**一開始你可能靠介紹、靠幾個熟客撐著，看不出差別。** 但等你真的要靠廣告帶人的時候，低利潤會直接變成天花板。

> **高價不是為了多賺，是為了讓廣告開得起來。**

### 你能開多少價，看兩件事

**第一：他有多痛。**

這是主要的。**一個真的痛的人，預算是可以被突破的**——他會去想辦法，分期、動用存款、跟家人商量。

而一個不太痛的人，你再便宜他也只是「再看看」。

**所以 2.1 挖出來的那句恐懼，直接影響你的價格。** 你承諾的東西越靠近他真正在怕的，他的預算彈性越大。

**第二：他有沒有東西可以拿來比。**

這是次要的，但它決定他的**第一反應**。

你說自己是「數學家教」，客人心裡就有一個行情（一小時多少）。第一反應會是「你怎麼比別人貴」。

你說自己是「解題方法教學」，那個類別沒有行情——**他沒有東西可以拿來比，所以他會先問「那是什麼」。**

**這兩個問題差很多。** 前者你要辯解，後者你可以說明。

所以 2.3 那一格如果填成交付形式（家教、課程、諮詢），**你等於主動把自己放進一個有行情的格子裡。**

## 三、方法：四個價值槓桿

價值不是「我給了多少東西」，而是這四件事：

| 槓桿 | 問題 | 怎麼加強 |
|---|---|---|
| **1. 結果多想要** | 這是不是他半夜在想的那件事？ | 把承諾往「恐懼那一層」靠 |
| **2. 成功機率多高** | 他相信自己做得到嗎？ | 明確流程、案例、陪跑、篩選 |
| **3. 多快拿到** | 要等多久才看得到？ | 設計一個「第一週就看得到」的小成果 |
| **4. 多輕鬆** | 他要付出多少力氣？ | 模板、工具、檢查表 |

### 大部分人只在第 4 格加東西

多送十支影片、多送一份講義、多送一個社群。

**那是四格裡最不值錢的一格**，而且加太多反而會讓人焦慮——**東西那麼多我怎麼看得完。**

### 真正撐得起高價的是第 2 格

**客人最大的懷疑不是「這方法有沒有用」，是「我做不做得到」。**

他過去買過的每一堂課、每一個服務，都在提醒他這件事：他買了，然後沒做完。

所以你要處理的不是「方法好不好」，是**他一個人做不做得下去**。

### 第 1 格要往恐懼那一層靠

2.1 你挖出來的那句恐懼，用在這裡。

| | 承諾的層次 | 例子 |
|---|---|---|
| 弱 | 表面痛 | 「幫你的孩子把數學補起來」 |
| 中 | 真正要的結果 | 「讓他自己會寫」 |
| **強** | **恐懼那一層** | **「讓你知道他不是天生不行」** |

**越往下，客人越想要，因為那才是他真正在怕的。**

但承諾恐懼層有一個前提：**你要拿得出東西。**

我跟家長講「他的能力真的沒有問題」的時候，不是只講一句話。**我會舉實際的案例**——有些孩子一開始的狀況比她的孩子更差，但短時間內做出了突破。

**一句承諾＋一個真實案例，才撐得住。**

只有承諾沒有案例，那是安慰；有案例，那是證據。

## 四、方法：定價三問

不要從成本算。從這三個問題算：

**1. 他省下什麼？**

時間、學費、走錯路的三年。

**2. 他得到什麼？**

可以量化的話就量化。

**3. 他不做的代價是什麼？**

維持現狀，一年後他在哪裡。

### 第 3 問最有力

因為**不做也是有代價的**，只是大部分人沒算過。

一個家長猶豫兩萬塊的時候，她心裡算的是「這兩萬值不值」。

**你的工作是把另外那一邊也攤開來給她看。**

### 第 3 問寫不出來的話

代表你的產品可能不夠必要——**不做也沒差的東西，很難賣。**

回 2.1 看恐懼那一層。恐懼是最好的第 3 問素材，因為恐懼講的就是「如果一直這樣下去會怎樣」。

## 五、高價要有三根支柱撐著

價格開得高，要有三樣東西撐著。**少一根就會塌：**

| 支柱 | 內容 |
|---|---|
| **明確的結果** | 講得出他會拿到什麼，不是「你會學到很多」 |
| **明確的流程** | 講得出第一週做什麼、第二週做什麼 |
| **明確的篩選** | 講得出你不收誰 |

**第三根最反直覺，但它最有力。**

> **「不是誰都能買」本身就是價值訊號。**

什麼人都收的東西，客人會自動判斷它不值錢。

而且這一根你階段一已經有了——**1.4-B 你用兩個測試找出來的「我不收誰」，就是這一根。**

**三根的檢查，作業 2.4-C 會帶你走。**

## 六、案例｜易學院為什麼敢開這個價

### 四槓桿盤點

| 槓桿 | 我有的 | 分數 |
|---|---|---|
| 1. 結果多想要 | 家長要的是「知道孩子卡在哪」，這正好是她最焦慮的 | 3 |
| 2. 成功機率多高 | 三步驟解題法、試聽當場就能指出卡點 | 3 |
| 3. 多快拿到 | 第四堂課就看得到孩子願意動筆 | 2 |
| 4. 多輕鬆 | 一對一，不用家長自己盯 | 2 |

**我最強的是第 1 和第 2 格，這是對的。**

第 1 格我承諾的不是「進步幾分」，是「**你會知道他卡在哪**」——那更接近恐懼那一層（我怕他天生不行）。

第 2 格我給的不是保證，是**一個看得見的流程**。試聽當天我就能指出孩子卡在三步驟的哪一步——**那讓家長相信「這個老師知道自己在幹嘛」。**

### 定價三問

**1. 她省下什麼？**

省下再換一家補習班的兩萬塊，和再浪費的半年。

**2. 她得到什麼？**

一個明確的答案：孩子卡在哪一步，還有多久能補起來。

**3. 她不做的代價？**

**這一問我不算錢，我算孩子的處境。**

現在國二，一年後就是國三。國三要補的不只是新進度，還要回頭補前面兩年——**同樣的問題，在時間壓力底下處理，難度完全不一樣。**

而且更重要的是：**那個壓力是孩子在扛。**

現在他還有時間慢慢建立起「我做得到」的感覺。到了國三，每一次考試都在提醒他來不及了——**那時候他不只要補進度，還要先對抗「我就是不行」這個念頭。**

**這才是真正的代價。**

### 為什麼這樣講比算錢有力

算錢，家長會開始比較「這兩萬跟那兩萬」。

**算孩子的處境，她比較的是「現在」跟「一年後」。**

而且注意我沒有說「不補會考不上」——**那是恐嚇，而且我不能保證。**

我講的是一個時間的事實：國二處理和國三處理，難度不一樣。

**恐嚇和算帳的差別在於，算帳是可以驗證的。**

## 七、常見錯誤

**錯誤一：用成本定價**

「我花了 40 小時做，所以要賣多少」——客人不在乎你花多久，他在乎他拿到什麼。

**錯誤二：照著同業定價**

你抄他的價格，等於接受他的定位。**而你和他的定位不一定一樣。**

這一條跟前面那件事是同一回事：**你如果已經開了一個新類別，就不該用舊類別的行情定價。**

**錯誤三：用降價換成交**

降一次，這個客人以後每次都會等你降。

永遠記得「價值＝價格」。

**錯誤四：三根支柱缺一根，用降價補**

流程講不清楚、篩選講不出來，然後想用「現在報名折三千」把它蓋過去。

**蓋不過去。** 客人猶豫的是「我做不做得到」，不是「三千塊」。

*缺哪根補哪根。*

## 八、這一節你要產出什麼

到作業本**任務 2.4**，你會產出三樣東西：

1. **四槓桿的分數**，而且知道最弱的是哪一格
2. **定價三問的答案**
3. **一個價格**，而且三根支柱都在

作業還會帶你做兩件事：**三根支柱的檢查**，和**產品階梯**（入口／主力／延伸）。

產品階梯只有**主力那一列一定要填**——入口和延伸現在沒有很正常，先空著。

> 高價不是為了多賺，是為了買得起流量，更是對得起你的付出。

# 2.5 賣爆的成交環節

## 一、這堂課要解決的問題

東西不錯、價格合理、對方也聽得很認真。

然後他說：「**我再想想。**」

然後就沒有然後了。

> **注意：這堂課處理的是「成交方案要怎麼設計」，不是「怎麼跟人談」。**
>
> 對談的技術在階段六。這裡先把產品本身組到對的樣子。
>
> **成交方案設計錯，話術再好也救不回來。**

## 二、核心觀念：「我再想想」不是價格問題

九成的人聽到「我再想想」，直覺是「太貴了」，然後開始想要不要降價。

**降價救不了，因為問題不在價格。**

「我再想想」背後其實是三個沒被解決的疑慮：

| 疑慮 | 他心裡在想 | 你要給什麼 |
|---|---|---|
| **1. 我不信這有用** | 這方法真的行嗎？ | 證據 |
| **2. 我不信我做得到** | 別人可以，我不行 | 流程與陪伴 |
| **3. 我不急** | 之後再說也可以 | 真實的時間理由 |

### 這三個疑慮，你前面已經處理過兩個了

**這一節不是全新的東西。** 前面幾節做的事，剛好對到這三格：

| 疑慮 | 你在哪裡已經準備過 |
|---|---|
| **1. 我不信這有用** | 階段一 1.1-C 你選的切角（經歷／方法／成果），那就是你的證據 |
| **2. 我不信我做得到** | 2.4 四槓桿的第 2 格「成功機率多高」 |
| **3. 我不急** | **沒有處理過。這一節才第一次碰。** |

所以這一節的重點是：**把已經有的東西組起來，然後補上第三格。**

## 三、方法：三個疑慮，三個解法

### 疑慮 1：我不信這有用 → 給證據

三種證據，強度不一樣：

| 證據 | 對誰最有效 |
|---|---|
| **你自己走過的過程** | **冷受眾最買單**——他不認識你，但他相信「走過同一條路」 |
| **真實個案** | 已經有點信任你的人。**據實呈現，不誇大** |
| **可以驗證的東西** | 一個網站、一個看得到的成果、一份公開的紀錄 |

**你在階段一 1.1-C 選的那個切角，就決定了你主要用哪一種。**

選經歷型的，用第一種；選方法型的，用第三種（把方法本身攤開來給他看）；選結果型的，用第二種。

### 疑慮 2：我不信我做得到 → 給流程與陪伴

**這一格最重要，而且最少人做。**

因為所有競爭者都在解疑慮 1——大家都在證明「我的方法很棒」。

但客人心裡真正的障礙是：

> **「我知道它很棒，但我知道我不會做。」**

**他過去買過的每一堂課，都證明了這件事。**

所以你要處理的不是「方法好不好」，是**他一個人做不做得下去**。

**解法：**

- 把流程拆到「**明天早上第一件事**」的顆粒度
- 給**成品模板**，不是給觀念（他要的是可以直接改的東西）
- 最強的一句：

> **「你不用自己想清楚全部，我陪你做出第一版。」**

**這句話為什麼有力？**

因為他真正害怕的是**第一版永遠做不出來**。

**你把那個恐懼直接接手了。**

### 疑慮 3：我不急 → 給真實的時間理由

稀缺可以用，但**必須是真的**。

- ✓ 「這一梯只收 10 位，因為一對一陪跑我一次帶不了更多。」
- ✗ 「限時倒數三天！」（然後三天後又開一次）

**假稀缺被抓到一次，信任就歸零。**

真實的稀缺理由通常有三種：**你的時間上限、梯次的開課時間、價格會調整的真實原因。**

#### 但還有一種更強的，而且不用你製造

**看看你的行業有沒有一個外部的時間表。**

例如：升學考試、季節（夏天前要瘦、過年前要整理）、證照考試的梯次、對方的年紀（越大越難處理的事）。

**如果有，那就是你最好的稀缺**，因為：

| | 一般的稀缺 | 外部時間表 |
|---|---|---|
| 來源 | **我訂的**（只收 10 位、限時三天） | **外部訂的**（會考、季節、年紀） |
| 客人的反應 | 會懷疑「是不是話術」 | 不會懷疑，因為那是事實 |
| 會不會過期 | 會，過期之後要重新編一個 | **不會，它自己在跑** |

**你不需要製造急迫感，你只需要把那個時間表指出來。**

#### 有一條線不能過

指出時間表是**陳述事實**，加上後果預測就變成**恐嚇**。

- ✓ 「明年這個時候，剩不到一百天」——事實，他自己會算
- ✗ 「現在不處理，到時候一定來不及」——後果預測，而且你不能保證

**差別在於：前面那句你講完就停，後面那句你替他把結論下了。**

**而人不喜歡別人替他下結論。**

#### 完全沒有時間表怎麼辦

**那就不要製造。** 誠實比急迫感值錢。

但還有一條路——**用「等待的代價」。**

這就是 2.4 定價三問的第 3 問：他不做的代價是什麼。

| | 稀缺 | 等待的代價 |
|---|---|---|
| 講的是 | **我這邊的限制**（只收 10 位） | **他那邊的損失**（再拖一年會怎樣） |
| 需要 | 一個真實的限制 | 一個真實的時間事實 |
| 風險 | 假的會被抓到 | **講過頭會變恐嚇** |

**沒有限制可以講的人，用第二種。** 而且第二種通常更有力，因為它講的是他自己的事，不是你的規定。

## 四、方法：成交方案的三層結構

| 層 | 內容 | 目的 |
|---|---|---|
| **主體** | 他真正買的那個結果 | 解決疑慮 1 |
| **加值** | 讓執行變快的東西（模板、工具、檢查表） | 解決疑慮 2 |
| **降風險** | 陪跑、分階段、明確的退出機制 | 解決疑慮 2 和 3 |

### 加值不是越多越好

送太多會有兩個反效果：**看起來很虛，而且會讓人焦慮。**

加值的判斷標準只有一個：

> **這東西能不能讓他更快做出第一版？**

不能就拿掉。

### 注意「加值」和「主體」的差別

很多人會把加值堆到比主體還多，然後客人開始懷疑：**主體是不是不夠好，所以要送這麼多？**

**主體是他真正買的東西。加值只是讓那件事快一點。**

如果你的加值清單比主體的描述還長，**那個比例就錯了。**

## 五、案例｜易學院的成交方案長什麼樣

### 三個疑慮，我的解法

| 疑慮 | 我給的 | 強度 |
|---|---|---|
| **1. 我不信這有用** | 試聽課。當場指出孩子卡在三步驟的哪一步 | 3 |
| **2. 我不信我做得到** | 一對一我自己帶，而且讓孩子當場說出願意 | 3 |
| **3. 我不急** | **不用我製造——會考倒數自己在跑** | 3 |

> **三格都滿分不是因為我特別厲害，是因為這門生意的結構剛好幫了我：**
> 有試聽（證據）、有一對一（陪伴）、有會考（時間表）。
>
> **你要看的不是我幾分，是你的生意結構裡有什麼是現成的。**
> 有些人的三格天生就有兩格，有些人三格都要自己做。**先盤點，再補。**

### 疑慮 1 我用的是「可以驗證的東西」

我在階段一 1.1-C 選的是**方法型**，所以我不講「我以前也是這樣」，我**直接把方法攤開來**。

而試聽課就是那個攤開的動作——**家長不是聽我說方法有用，是當場看到方法在她孩子身上運作。**

**這比任何證言都有力，因為她看到的是她自己的孩子。**

### 疑慮 2 在我這裡有一個特殊的地方

一般來說疑慮 2 是「客人自己做不做得到」。

**但我的生意裡，要動的人不是付錢的人。**

家長買的時候，她在擔心的是——**「我的孩子會配合嗎？」**

所以我解疑慮 2 的方式不是給家長模板，是**在試聽當天讓孩子自己說出「我願意試試看」**。

**那句話是給家長聽的。** 她聽到孩子自己這樣講，疑慮 2 就解了一半。

#### 但我在同一個動作裡，其實在做三件事

| 我在看什麼 | 這件事屬於 |
|---|---|
| 讓家長聽到孩子願意 | **成交方案**——解她的疑慮 2 |
| 確認孩子真的有狀態、教得動 | **篩選**——就是階段一 1.4-B 那兩個測試 |
| 確認家長的付費意願到哪 | **成交**——她接下來會問什麼、怎麼問 |

**一個動作，三個用途。**

這不是我設計得特別聰明，是因為**這三件事本來就綁在一起**——孩子願不願意、家長信不信、她付不付錢，同一場對話裡就看得出來。

> **如果你的生意也是「付錢的人 ≠ 要動的人」，那你一定要設計一個環節，讓那個要動的人出現。**
>
> 因為那個環節同時幫你做三件事：**解疑慮、做篩選、判斷意願。**
>
> 而且這三件事你自己去做都很費力——**讓他們本人出現，一次解決。**

### 疑慮 3：我什麼都沒做，但它是滿分

我沒有梯次制、也沒有「只剩兩個名額」——那種稀缺我沒有。

**但我有一個更強的：孩子的年紀。**

國二下和國三上，家長的急迫感完全不同。而**那個時間表不是我訂的，是會考訂的。**

所以我不用說「快來報名」。我只要把她自己心裡在算的那筆帳講出來：

> 現在國二，還有一年多。
> 明年這個時候，剩不到一百天。

**這句話不需要任何催促的語氣，家長自己就會算。**

而且注意我講完就停——**我沒有接「所以現在不處理就來不及了」。**

那句話一加上去，就從陳述事實變成恐嚇，而且我不能保證。

## 六、常見錯誤

**錯誤一：加值堆到滿**

十個贈品不會讓人更想買，只會讓人懷疑主體不夠好。

**錯誤二：用折扣代替價值**

折扣只會訓練客人等你降價。

**錯誤三：只處理疑慮 1**

把所有力氣花在證明方法有效，完全沒處理「他做不做得到」。

**這是最多人犯、也最貴的錯。**

**錯誤四：用假稀缺處理疑慮 3**

「限時三天」然後三天後又開一次——**被抓到一次，前面兩格做得再好都沒用了。**

*先看你的行業有沒有外部時間表。沒有的話，用等待的代價。不要編。*

## 七、這一節你要產出什麼

到作業本**任務 2.5**，你會產出四樣東西：

1. **三個疑慮的解法**，而且知道最弱的是哪一個
2. **一句「你不用＿＿，我會＿＿」**
3. **成交方案的三層結構**（主體／加值／降風險），加值刪過一輪
4. **一個真實的時間理由**

第四樣作業會先問你一件事：**你這一行有沒有一個不是你訂的時間表。**
有的話就用它，不用做稀缺；沒有的話才走真實的稀缺，兩個都沒有就用等待的代價。**三條路走一條。**

作業還會帶你選一個**價格的對比框架**——三選一，勾一個就好。

> 客人最大的障礙不是不相信你，是不相信自己。

# 2.6 階段二總結

## 你在這個階段拿到的東西

1. **市調三張表**
   需求分三層、競品拆五欄、找出空白地帶

2. **畫像六格 + 一個時刻**
   從一群人縮到一個人

3. **對抗定位三步驟**
   找共同前提、反過來、過三個測試

4. **四個價值槓桿 + 三根支柱**
   價格開得起來的理由

5. **三個疑慮 + 成交方案的三層結構**
   處理「我再想想」

## 你要帶去階段三的東西

階段三要教你寫文案和做廣告圖。

但**文案不是憑空寫出來的**——它是把你這一階段填的東西，翻譯成客人聽得懂的話。

| 你手上的 | 階段三會拿它做什麼 |
|---|---|
| **他的那個時刻**（2.2-B） | 變成你的**廣告第一句** |
| **恐懼那一層**（2.1-A） | 變成最刺的那幾個鉤子 |
| **「大家都覺得＿＿，但我主張＿＿」**（2.3-A） | 變成**反直覺鉤子** |
| **濃縮版定位句**（2.3-D） | 變成廣告標題、圖上那一句話 |
| **「你不用＿＿，我會＿＿」**（2.5-B） | 變成 **CTA 前一句** |
| **成交方案的三層結構**（2.5-C） | 變成文案後段的「機制條列」 |

**你在這一階段寫下的定位句，會變成階段三每一篇文案的第一句話。**

所以這一階段寫得越清楚，後面越省力。

## 哪一格填得虛，階段三就會卡在哪

這件事要先講，因為到了階段三你會發現——**卡住的地方不是文案能力，是這一頁還沒想完。**

| 階段三你會卡在 | 回來補哪一格 |
|---|---|
| 寫不出第一句、每次開頭都在「大家好」 | **2.2-B 那個時刻**——你沒有畫面，所以只能寫招呼語 |
| 寫得出來，但每一句都很客氣、沒有人停下來 | **2.1-A 恐懼那一層**——你只挖到表面痛 |
| 三版文案改來改去都差不多 | **2.3-A 共同前提**——你沒有一個可以反過來的主張，所以只能換形容詞 |
| 文案寫得動人，但沒有人點 | **2.3-D 濃縮版**——你的那一句話不夠像一句話 |
| 寫得出來，但結尾很軟，不敢叫人行動 | **2.5-B**——你自己還不確定要承諾什麼 |

**這張表你現在不用背。**

等你到了階段三真的卡住的時候，回來對一次——**九成的情況，答案都在上面。**

## 一件事要先講

階段一我跟你說：不確定就寫「暫定」。

**階段二不一樣，這一階段的東西要定下來。**

不是因為它不能改，是因為**後面四個階段都在放大這一頁**。放大器不會修正錯誤，它只會把錯誤放得更大。

所以在往下走之前，把附錄那一頁的定位藍圖唸一次給自己聽。

> **唸的時候只問一個問題：我自己相信嗎？**

如果有哪一格唸出來會心虛，那就是還沒好。回去改那一格。

**不用改到完美，改到你自己不心虛就夠了。**

## 這個階段的定調句

> 定位不是把你變得更好，是讓你在客戶心裡變得不一樣。
